## 🖥️ Run the Website Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/hamdan-raja-portfolio.git
   ```

2. Navigate to the project folder:

   ```bash
   cd hamdan-raja-portfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

Replace `YOUR-USERNAME` with your GitHub username.

## 🌍 Deploy with GitHub Pages

1. Push the website files to your GitHub repository.
2. Open the repository's **Settings**.
3. Select **Pages** under **Code and automation**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and the `/(root)` folder.
6. Click **Save** and wait for the deployment to finish.

Your website URL will generally follow this format:

`https://YOUR-USERNAME.github.io/hamdan-raja-portfolio/`

Make sure `index.html` is in the selected publishing folder and that all required website assets are included.
